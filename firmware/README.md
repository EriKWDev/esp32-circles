# Firmware

| Path | Purpose |
| --- | --- |
| `xiaozhi/` | Preserved XiaoZhi source snapshot |
| `factory_firmware/` | Prebuilt recovery images supplied with the product |

The two paths have different provenance and are retained as supplied. They are
not modified, compiled, packaged, or validated by this repository's CI.

See [Firmware artifacts](../docs/FIRMWARE.md) for release-bundle contents and
the product wiki for recovery flashing instructions.
