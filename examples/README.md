# Examples

The repository provides parallel learning paths for ESP-IDF and Arduino:

- `esp-idf/` contains independent projects validated against maintained ESP-IDF
  5.5 and 6.0 releases.
- `arduino/examples/` contains independent sketches validated with the
  repository's pinned Arduino-ESP32 core.

The numeric prefixes order examples from focused peripheral checks to display,
audio, and UI integration. They do not express build dependencies.
