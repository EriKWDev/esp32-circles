# Support

For setup, pinout, recovery flashing, and product-specific questions, start with
the [English wiki](https://www.waveshare.com/wiki/ESP32-C6-Touch-AMOLED-2.16)
or [中文 Wiki](https://www.waveshare.net/wiki/ESP32-C6-Touch-AMOLED-2.16).

Use GitHub Issues for reproducible repository defects. Include the board
revision, source commit, example or firmware path, framework version, complete
logs, and whether the result came from CI or physical hardware.

Do not post credentials, device certificates, private network details, or other
sensitive information.
