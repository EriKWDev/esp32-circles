# Support

[简体中文](SUPPORT_ZH.md)

For setup, pinout, recovery flashing, and product-specific questions, start with
the [official product documentation](https://docs.waveshare.com/ESP32-C6-Touch-AMOLED-2.16).
For account, order, or private product-support matters, use the
[Waveshare support portal](https://docs.waveshare.com/support).

Use GitHub Issues for reproducible repository defects. Include the board
revision, source commit, example or firmware path, framework version, complete
logs, and whether the result came from CI or physical hardware. A green compile
does not establish display, touch, audio, PMU, storage, RF, or power behavior.

Do not post credentials, device certificates, customer data, private network
details, or other sensitive information. Report suspected vulnerabilities by
following the [Security policy](SECURITY.md), not through a public issue.
