# Release artifacts

[简体中文](README_ZH.md)

Release bundles are generated by scripts under `.github/scripts/` after a
successful example CI build. Generated files are written to
`release-artifacts/`, uploaded by the workflow, and never committed.

Every archive includes a manifest with the source commit, exact framework
version, target, binary names, and normalized flash offsets. ESP-IDF archives
also contain a rewritten `flasher_args.json` whose paths refer to bundled
`bin/` files instead of the CI build directory.

Archives use portable file permissions, with `flash.sh` executable and data
files read-only by default. Both flash helpers use the same manifest order.
Packaging fails on ambiguous binaries, path escapes, duplicate offsets or names,
or unsafe filenames rather than emitting a questionable release artifact.
