# 发布产物

[English](README.md)

示例 CI 构建成功后，`.github/scripts/` 下的脚本会生成发布包。生成文件写入
`release-artifacts/` 并由工作流上传，永远不会提交到仓库。

每个压缩包都包含 schema version 1 清单，其中记录开发板、芯片、源码工程、源码提交、
精确框架版本和 921600 波特率烧录设置。每个包内文件保留原有 address/file 条目，并增加
包内路径、偏移、字节大小和 SHA-256 哈希。ESP-IDF 压缩包还包含重写后的 `flasher_args.json`，
其中路径指向包内 `bin/` 文件，不再引用 CI 构建目录。

压缩包使用可移植文件权限，`flash.sh` 可执行，数据文件默认只读。两个烧录辅助脚本
采用相同清单顺序。遇到歧义二进制、路径逃逸、重复偏移或文件名以及不安全文件名时，
打包会直接失败，不会输出可疑发布产物。
