# Firmware artifacts

[简体中文](FIRMWARE_ZH.md)

Source snapshots, immutable recovery inputs, and generated example artifacts are
intentionally separate:

- `firmware/xiaozhi/` is a preserved upstream source snapshot labeled 2.2.5.
- `firmware/factory_firmware/` contains prebuilt recovery images retained from
  the original repository.
- `release-artifacts/` is generated by example CI and is never committed.
- neither preserved firmware path is modified, built, packaged, or validated by
  the default repository workflows.

These hashes document the repository inputs; they are not signatures and do not
establish authenticity or hardware suitability. Do not rename, regenerate, or
replace an image without recording its source, version, expected flash process,
new checksum, and hardware validation result.

Use recovery images only with the offsets and procedure in the
[official product documentation](https://docs.waveshare.com/ESP32-C6-Touch-AMOLED-2.16).
A successful build of current XiaoZhi source would not certify that a historical
binary is reproducible from it. CI artifacts cover the example projects, not the
preserved firmware paths.
