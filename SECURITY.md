# Security policy

Please do not disclose suspected vulnerabilities in a public issue before the
maintainers have had an opportunity to assess them. Use the repository owner's
private security-reporting channel when available.

Include the affected source commit, component, impact, reproduction conditions,
and any proposed mitigation. Do not include real credentials, provisioning
secrets, or customer data.

This repository does not provide security updates for bundled third-party
projects independently of their upstream maintainers.
