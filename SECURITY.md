# Security policy

[简体中文](SECURITY_ZH.md)

Do not disclose a suspected vulnerability in a public issue before maintainers
have had an opportunity to assess it. If GitHub shows a **Report a
vulnerability** action for this repository, use it. Otherwise, submit a private
ticket through the [Waveshare service portal](https://service.waveshare.com/)
and identify the report as security-sensitive.

Include the affected source commit, component, impact, reproduction conditions,
and any proposed mitigation. Do not send real credentials, provisioning secrets,
customer data, device certificates, or unnecessary private network details.

This repository does not provide security updates for bundled third-party
projects independently of their upstream maintainers. Identify the affected
path so the report can be routed to the responsible project.
